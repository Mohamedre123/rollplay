# El Mundo Hispano · Role Play

Sitio web responsive para practicar conversación en español en formato de retos aleatorios.

- `index.html`: nivel A1.1 con siete retos y selección aleatoria sin repeticiones.
- `a1-2.html`: plantilla visual preparada para el nivel A1.2.
- `assets/`: logo suministrado e imagen de ambientación generada para el proyecto.

Para verlo, abre `index.html` en un navegador. No requiere instalación.
